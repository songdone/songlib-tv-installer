## 下一位接手者必须先做

1. **完成最后一轮布局**：第二排左体验卡、右购买与激活流程，与上排基础版/Pro 的列宽和左右边缘一致，顶底对齐；小屏堆叠。共享列网格已改，`sl-purchase-support` / `sl-activation-guide` 的局部样式尚未补齐和验收。不要再把体验卡拉成全宽。
2. 用浏览器验证桌面 1440/1024 与手机 390/360，检查等宽、等高、CTA 可见、长标题换行、商品图完整展示，保存新截图。现有截图大部分是先前布局，不能冒充本次最终检查。
3. 体验卡的开放门控尚未闭环：Go 返回 `trial_open` 和 `trial_url`，页面仍依据 `links.trial` 的固定官网锚点显示按钮，未使用开放状态。默认情况下不能宣称 30 天体验已真实上线。只做官网跳转，不在安装助手输入/保存商业激活码。
4. 购买按钮默认仍回落 16688 店铺，而非特定音屿商品页。商品页已由所有者确认，下一轮应统一公开产品配置，不能让两个套餐指到同一店铺而称为“直达商品页”。价格仍需可信配置，不要硬编码商店旧价。
5. 价格显示仍用 `Math.floor(amount / 100)`，会丢失角分；Go 的缺失 amount 当前默认整数 0，也可能误显示免费。修正金额字段可选性和格式化，补单元测试。
6. 版本尚未全同步：diagnostics 硬编码 0.1.3，Compose/模板引用 0.1.3 镜像，Release 文档仍为 0.1.3。未发布 1.0.1 镜像；不能把当前薄 FPK 当作装入新版 UI 的工件。先完成发布一致性检查，等待批准后才发布。
7. 套餐对比的“基础版免费功能”有误导风险（免费的是安装助手，不是付费播放器基础版），以及 FAQ 中“购买按钮缺失”的旧描述，需要更新。
8. trial 商品图同时写“30 天”和“永久授权 · 最多 6 台”；须让所有者明确并修正素材/说明。不能将试用图中的永久授权当作真实试用规则。
9. 核实官网代理与私有销售 API 的实际部署状态。当前只完成本地接口/代码验证，没有证明官网已上线新配置。
