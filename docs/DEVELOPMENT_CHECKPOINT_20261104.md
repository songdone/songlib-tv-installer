### 2. 体验卡开放门控

- `web/songlib_product.go`：新增 `validClaimURL`，只接受 https 且主机为 `songlib.playsong.cn` / `www.songlib.playsong.cn` 的 `claim_url`；`trial_days` 只在 1–365 范围内采用。校验不过就不下发 `trial_url`，`trial_open` 保持 false。
- `web/static/src/utils/songlib-config.mjs`：前端再校验一次（https + 官方主机），`trialIsClaimable()` 同时要求开放状态与合法链接。
- 页面：开放时显示「前往官网领取」，未开放时标签变「暂未开放」、按钮换成说明文字（「体验活动开放时间以官网公告为准」），不再用官网固定锚点冒充可领取。

### 3. 购买按钮直达各自商品页

- 上一条的店铺回落已删除：`SONGLIB_16688_SHOP` 不再作为套餐兜底，避免两个按钮都落在店铺首页还称为「已对接」。
- 默认值改为所有者确认的商品页：基础版 `G41709534`、Pro `G49510548`；`/songlib/config` 只可能用另一个通过校验的 16688 商品链接覆盖。
- 首页 Hero 与购买页实测均指向各自商品页。

### 4. 价格精度

- 前端新增 `formatPlanPrice()`：保留角分（6800→68、12850→128.50），0/负数/缺省一律返回 null 不渲染，不再出现 `Math.floor` 截断或误显示「¥0」。
- Go 的 `amount` 改为 `*int`，只有「下发且 > 0」才算有效价格；缺字段与 0 都视为未定价。

### 5. 文案与版本

- 对比表头「免费功能 / 基础版包含」改为「基础版功能 / 需购买基础版」——免费的是安装助手，不是基础版播放器。
- FAQ 第 5 条由已过时的「购买按钮没有显示怎么办」改为「为什么点购买会跳到 16688」。
- 体验卡说明改为描述机制（「体验卡在官网领取、在播放器内激活」），不再是无条件领取指令。
- 五语言（zh_cn / en / sv / sr / sr-Latn）同步，新增 `trial_tag_idle`、`trial_closed`。
- `/songlib/diagnostics` 的 `version` 改为读取 `build.Version`（当前 1.0.1），不再硬编码 0.1.3。

## 仍未完成（按优先级）

1. **1.0.1 未形成可交付工件**：diagnostics 已跟随版本号，但 Compose 模板、`packaging/fnos` 与 Release 文档仍引用 `0.1.3` 镜像；没有已发布的 1.0.1 多架构镜像前，不能出「引用旧镜像的新 FPK」。
2. `validBuyURL` 仍允许任意 `/goods/xxx` 路径；若要防错链，可再校验商品号白名单（G41709534 / G49510548）。
3. 官网代理与私有销售 API 的实际部署状态未核实；本轮只验证了本地接口行为。
4. 私有仓 sales adapter（分页、多卡/退款、金额换算、卡密上传回执）与六台授权迁移的真实存量演练未推进——属私有仓范围，需要单独批准。
5. 真实 fnOS 生命周期、Apple TV 配对/签名/安装、7 天续签观察仍未验收。
