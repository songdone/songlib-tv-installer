# Apple 账户与签名

1. 专门注册用于自签的小号，启用2FA，保存恢复方式；不要用存照片/支付/个人资料的日常主账号。
2. 无需退出电视主账号。安装助手签名账号与电视当前账号分别管理。不支持App专用密码。
3. 免费Personal Team签名通常7天到期。Apple当前规则还限制App ID与设备数，详见 https://developer.apple.com/help/account/basics/about-your-developer-account 。不要把商业六台授权误认为Apple可登记六台。
4. 设备发现后进入配对，按电视提示输入验证码；网络不支持mDNS可在上游手动IP流程添加（设备连通性另测）。
5. 上传合法tvOS IPA，确认目标设备、账户、签名信息再安装。外部P12+tvOS描述文件路径保留，无需Apple账户，但不会自动延长证书期限。
6. NAS离线/Apple风控/电视休眠/2FA/配额耗尽可造成失败，查看状态后手动重试。签名到期不能启动，音屿授权到期则是播放器权益限制，两者不同。
7. 未做7天周期观察，自动续签长期稳定性待观察。
